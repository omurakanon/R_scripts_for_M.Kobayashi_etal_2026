# R scripts for M.Kobayashi et al. 2026

### for_Figure1.Rmd
This R script is for analyzing iChIP data treated in the Figure 1 of the manuscript.

### iChIP_input.csv
It is input file for the above.


### for_Figure6_Ctrl_vs_Mock.Rmd
This R script is for comparing Ctrl vs Mock of GLT binding proteins in the Figure 6 of the manuscript.

### GLT_associated_Ctrl_vs_Mock.rnk
It is input file for the above.


### for_Figure6_siFbl_vs_Ctrl.Rmd
This R script is for comparing siFBL vs Ctrl of GLT binding proteins in the Figure 6 of the manuscript.

### GLT_associated_siFbl_vs_Ctrl.rnk
It is input file for the above.

See [the manuscript](https://www.biorxiv.org/content/10.64898/2026.11.05.761835v1) for details of the input files.
